## Deploy

Upload the **contents** of this folder to your web host or GitHub Pages for `social.cocomokio.com`.

For GitHub Pages:

1. Create a new repository (e.g. `cocomokio-social`)
2. Push this folder as the repo root
3. Enable GitHub Pages (Settings → Pages → Deploy from branch `main`)
